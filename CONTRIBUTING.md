# Contributing

Pull requests are welcome. **Sign the CLA first:** on your first pull request a bot comments with a
link to [`CLA.md`](CLA.md) and the line to reply with. Post it once; it covers every later pull
request. A pull request cannot be merged without it. What each licence here covers is in
[`LICENSING.md`](LICENSING.md).

`CLAUDE.md` and `src/README.md` explain how the project is laid out and which checks to run.
