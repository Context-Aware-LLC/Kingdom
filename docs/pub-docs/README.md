# Emberfall Player Guide

Emberfall is a turn-based digital card game about assembling a 30-card deck and outplaying one opponent at a time. The full game design lets a player build a Character from two classes; the current vertical slice centers on Emberward and Tidecaller. This guide collects the rules and policies a player needs without the project history or implementation detail behind them.

Emberfall is still in development. These pages describe the current rules baseline, not a release announcement. Features, balance values, availability, pricing, and platform support may change before launch.
