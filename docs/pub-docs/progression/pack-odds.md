# Pack Odds

Each pack contains **5 cards** drawn from that pack's set. All packs of the same type use the same odds and the same card pool, whether you bought them or earned them.

## Base odds per slot

These odds apply to each card slot on its own, before the guarantees below.

| Rarity | Chance per slot |
|---|---|
| Common | 64.0% |
| Rare | 26.5% |
| Epic | 8.0% |
| Legendary | 1.5% |

## Guarantees

- **Rare floor.** Every pack contains at least one Rare or better.
- **Epic pity.** If you open 9 packs in a row from a set without an Epic, your next pack from that set contains one.
- **First Legendary.** Your first Legendary from a set arrives by your 10th pack from that set.
- **Legendary pity.** After your first Legendary, you never open 40 packs in a row from a set without one.

Each set keeps its own count. Opening Pendingham packs does not affect your count for any other set.

When a pack owes you both an Epic and a Legendary, you get both.

## Duplicates

**A Legendary slot never gives you a Legendary you already own.** While a copy is in your collection, that card is out of your Legendary draws. Reduce it and it can be drawn again. Once you own every Legendary a pack can contain, a Legendary slot can only repeat one, and you still get the card.

**Common, Rare and Epic slots lean toward cards you are missing.** Within a slot's rarity every card can be drawn. How likely each one is depends on how many copies you already hold:

| Copies you hold | Relative chance |
|---|---|
| None | 100 |
| Some, below the deck limit | 70 |
| At or above the deck limit | 30 |

These are relative weights, not percentages. Copies you received earlier in the same pack count too.

**A pack never destroys or converts a card.** Copies beyond the 2 a deck may run (1 for a Legendary) stay in your collection. Your collection has no copy limit; only decks do.

Shards come from **Reduce**, in your collection, where you choose which copy to break down.
